# SkillBridge 🎓

### Learn Today, Grow Tomorrow.

SkillBridge is a web-based career guidance and skill assessment platform
that helps students evaluate their skills, explore career paths, and
identify areas for improvement.

## 📌 Project Objectives

- Help students explore different career options.
- Assess basic skills related to their chosen career.
- Display assessment scores and skill levels.
- Provide personalized learning recommendations.
- Track previous assessments and progress.
- Offer a structured learning roadmap.

## ✨ Features

- User registration and login
- Password hashing
- Career selection
- Skill assessment with automatic scoring
- Skill-wise assessment results
- Personalized learning recommendations
- Assessment history
- Dashboard analytics and progress charts
- Learning roadmap
- Separate user profile page
- Fetch API and JSON integration
- Responsive user interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- Tailwind CSS
- JavaScript
- Chart.js

### Backend
- Python
- Flask

### Database
- PostgreSQL (Neon)
